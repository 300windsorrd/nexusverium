# Improvements for "What's Coming" Feature

This document outlines potential improvements for the "What's Coming" section and its functionality.

## 1. User Interface & Layout
- **Grid Layout**: Move to a responsive 2x3 grid (3 columns x 2 rows) on larger screens to maximize space utilization.
- **Visual Status Indicators**: Add visual tags or progress bars to each pill indicating the current development phase (e.g., "Research", "Prototyping", "Testing").
- **Hover Effects**: enhance hover states to show a quick preview or "Learn More" prompt.

## 2. Functionality & Interactivity
- **Filtering & Sorting**: Allow users to filter items by category (e.g., Robotics, AI, Restoration) or sort by "Expected Completion".
- **Dynamic Content**: Fetch these items from a CMS or database (like Contentful or Sanity) instead of hardcoding, allowing non-developers to update the roadmap.
- **Subscription**: Allow users to subscribe to email updates for specific projects they are interested in.
- **Detailed Views**: Instead of a full page navigation, consider a slide-over panel or modal for quick consumption of details.

## 3. Engagement
- **Voting/Interest**: Add an "I'm interested" button to gauge community interest in specific upcoming features.
- **Timeline Integration**: Connect these items visually to the main timeline or "How We Build" steps to show where they fit in the larger lifecycle.
